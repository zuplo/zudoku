# Shipments Overview

The Shipments API books, tracks, and reroutes cargo across the seventeen charted systems. Every
manifest is quantum-signed at origin, so a container leaving Ganymede Station arrives with the same
checksum it departed with — even after three warp transits.

Start here, then head to **Shipment Management** to create your first booking.

## Before you launch

- Provision a warp token from the Cosmo Cargo console
- Pick a nearest-relay server so telemetry doesn't round-trip through the Kuiper belt
- Note that sublight fallback routes add roughly 4 parsecs to any quoted transit

This page sits ahead of the generated reference in the sidebar, and the **Shipments** tab lands here
rather than on the first endpoint — see the `landing` property in the navigation config.
